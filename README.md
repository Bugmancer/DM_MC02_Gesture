# DM-MC02 Gesture

## 项目介绍

基于 DM-MC02 开发板的动作识别项目，使用 BMI088 六轴传感器采集运动数据，在 STM32H723 上学习、识别并保存动作。最多支持 8 种动作，每种录入 1～20 次示范；上电后自动识别，无需连接电脑。

板端持续匹配最近一段运动，不用等整段运动结束。例如动作 A 做到一半，接着完整做 B，再继续 A，可在 B 完成附近识别 B。连续完整动作也可依次识别；重叠窗口会抑制重复事件。仍需要完整动作及足够匹配置信度，相似动作可能被拒绝。

配套网页可管理动作、设置 RGB 颜色和灯光持续时间，也可将识别结果映射为电脑快捷键。另有六轴数据查看、采集和三维空中画笔。画笔使用惯性数据估计短时轨迹，会有漂移，适合画短笔画。

## 使用说明

### 编译与烧录

使用 Keil MDK（ARM Compiler 5）打开 `MDK-ARM/DM_MC02_Gesture.uvprojx` 并编译，或在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File Tools/build.ps1 -Rebuild
```

通过 SWD 烧录生成的 `MDK-ARM/Build/DM_MC02_Gesture.hex`。命令行构建可用 `-CompilerBin` 指定 ARMCC 路径。重新用 CubeMX 生成工程后，先运行 `Tools/sync-project.ps1` 恢复自定义工程设置。

### 单独使用开发板

1. 上电后，左右选择空槽位，按 OK 开始学习。
2. 按住板载 KEY 做动作，松开结束。每次建议持续 0.2～2 秒；达到设定的示范次数后自动保存。
3. 再做相同动作，识别成功后亮起对应颜色。动作和设置保存在 Flash，断电后保留。

| 按键 | 操作 |
| --- | --- |
| 左 / 右 | 选择动作槽位 |
| OK | 空槽开始学习；已有动作按两次确认删除 |
| DOWN | 取消当前操作 |
| UP | 打开设置；上下选项目、左右调整，选保存退出后按 OK |
| KEY | 按住录制示范，松开结束 |

设置支持动作数量 1～8、示范次数 1～20、每槽 RGB 颜色和灯光持续时间 0.1～30 秒（默认 3 秒）。缩小动作数量只停用高编号槽位，不删除原有动作。多次示范在板端增量选择最多 3 个代表模板，避免录入次数增加后占用更多模型空间、增加每轮匹配耗时；每次示范都参与选择。示范次数多于 3 时，界面显示进度条和实际录入计数，保存后显示代表模板数。

### 使用网页

需要 Windows 和 Python 3.10+，首次启动需联网安装依赖。

1. 双击 `Start-GestureGUI.cmd`，用 USB 数据线连接开发板，在网页选择 STM32 串口并连接。
2. 在“动作库”选择空槽、准备学习，再按住板载 KEY 录入动作。数量、示范次数、颜色和灯光时长修改后，点击“保存到板子”。
3. 如需控制电脑，填写动作对应的快捷键，再打开“电脑快捷键”开关。快捷键作用于当前前台程序。
4. 在“空中画笔”页按住 KEY 绘制，松开结束；可旋转视角、撤销，并导出 PNG 或三维轨迹 JSON。
5. 用 `Stop-GestureGUI.cmd` 关闭服务，仅关闭浏览器不会断开设备。

没有开发板时可选择“演示设备”。本版固件为 `gesture-20261007-r10`，更多示范及连续动作识别改进需要烧录本版一次，旧动作模板和颜色可继续使用。灯光时长设置需 r9 或更新固件。

更多网页操作见 [GUI 使用说明](GUI/README.md)，配置与存储格式见 [配置文档](App/CONFIGURATION.md)。
