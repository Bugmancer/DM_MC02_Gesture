# 本地动作工作台

## 启动

双击项目根目录 `Start-GestureGUI.cmd`。首次启动建立独立的 `GUI/.venv` 并安装 pyserial 3.5、imufusion 1.2.11 和 numpy 2.2.6，需要 Python 3.10+ 和网络；本机已准备好依赖。后续界面、图表、Three.js 和图标都从本地加载，不连接云端。

默认地址为 `http://127.0.0.1:8765`，端口被占用时自动选择后续端口。重复双击会打开已有服务。双击 `Stop-GestureGUI.cmd` 停止服务和串口，关闭浏览器本身不会停止后台服务。

## 连板和学习

1. 使用数据线连接板子的 USB 接口，选择 `STMicroelectronics Virtual COM Port` 对应的 COM 端口。程序默认优先选择 STM32，收到有效 STATUS 才显示已连接。
2. 最新 `MDK-ARM/Build/DM_MC02_Gesture.hex` 为 `gesture-20261006-r9`，支持网页数量/RGB/持续时间设置和上电自动识别，修复候选匹配亮动作灯仅 200 ms 的问题，并包含 USB suspend/resume 修复；电脑端画笔仍兼容 r5。Keil 和命令行统一输出到这个目录。旧动作模板及 r8 配置兼容，无需重新学习。
3. 选空槽位，无需先校准或静止等待。“静止校准”是可选的陀螺仪零偏修正。
4. 点击“准备学习”或在板上选空槽按 OK，识别暂停。按住板载 KEY 开始一段示范，松开结束；每段建议 0.2～2 秒。相似动作会提示但仍计入；无效示范可重试，已接受次数保留。
5. r7 达到板端设定次数（1～3，默认 1）即自动写入 Flash、恢复识别；保存失败保留示范，可按板上 OK 或网页保存重试。旧固件保留手动保存流程。电脑不训练模型。
6. r7 无需网页开启识别，断开电脑仍识别。UP 进入板端设置：上下选择项目，左右修改动作种类数、示范数、颜色槽和 RGB；RGB 行左右粗调 17，OK 细调 1。选择保存退出后 OK 确认。动作种类数可设 1～8，缩小后高编号模板保留但不参与识别；GUI 同步实际颜色和设定次数。动作名称与电脑快捷键仍在本机保存。
7. 要控制电脑，单独打开“电脑快捷键”，如 `ctrl+shift+k`、`alt+left`、`space`。顶部“停止”取消当前学习/删除确认、关闭电脑快捷键；r7 随后仍自动识别并切灯。

动作名称和快捷键是本机按槽位保存的映射，模板在板上；更换另一块板子时应检查映射。连接、重新连接、设备重启、开始学习和断开都会关闭快捷键，不会自动恢复。

r9 在“动作库”上方提供“动作数量”（1～8）、“示范次数”（1～3）和“灯色持续时间”（0.1～30 秒，步进 0.1 秒，默认 3 秒），每槽 RGB 列可选灯色。调整后点击“保存到板子”，收到板端 Flash 保存确认才显示成功；失败保留草稿以便重试。缩小动作数量不会删除隐藏槽位的模板或颜色。学习、删除确认和保存期间暂时禁用配置控件；r8 仍可修改数量和颜色，持续时间需要 r9。板端 UP 设置仍可脱离电脑使用。

板端持续匹配，确认识别后 RGB 保持配置的时长；期间候选或未知动作不覆盖确认颜色，新确认动作立即换色并重新计时。候选只显示分数，动作标识灯由确认事件驱动。进入学习/设置或硬件错误可提前结束保持。重复“开启识别”不清掉现有保持计时。只有确认的动作事件参与电脑映射，并对连续运动防重复。

相似提醒不是录制失败。它表示新模板和某个已存动作接近，识别时可能无法确定类别；完全相同的两个类别不会被强行分配不同颜色。提醒中包含的已有槽位不会被覆盖或删除。

删除已存动作时，界面先请求板端进入确认态，收到确认后才允许“确认删除”。取消不会删除模板。开始学习前必须有同步的空槽位。

## 空间姿态

“空间姿态”使用 USB 收到的六轴数据计算相对姿态，并显示与空中画笔一致的位置点和轨迹。拖动三维视图旋转观察，滚轮缩放；归零按钮重置当前位置，复位视角按钮恢复相机，轨迹按钮控制轨迹显示。归零不会修改板端动作模板或校准。

固定世界参考系始终重力对齐、Z 轴向上，归零不会倾斜坐标轴；无板子模型。Fusion AHRS 连续跟踪方位，位移只在 KEY 按住时由 ESKF 轨迹模块估计，松键后经 RTS 回修并保持固定。没有独立的自由运行位移累加。六轴 IMU 的航向为相对航向。

## 空中画笔

连接设备后进入“空中画笔”，按住板载实体 KEY 并移动板子记录三维笔迹，松开立即抬笔并固定当前位置。无需点击网页开始按钮，也无需校准。鼠标拖动旋转视角、滚轮缩放，右键拖动平移，不会产生笔迹。居中按钮适配全部笔迹的视角。

支持换色、笔宽、视图缩放、撤销重做、清空确认、当前三维视图 PNG 及三维轨迹 JSON 导出。缩放仅改变相机，不改变笔迹坐标。草稿自动保存在当前浏览器；旧二维和板体参考系草稿单独保留。切换页面、隐藏网页、断连、数据中断或空间姿态归零会结束当前笔画。恢复后须先松开 KEY，再按下写下一笔；进入页面时已经按住 KEY 不会自动续写。学习动作时画笔暂停，防止同一次 KEY 同时录入两个工作流。

笔迹使用固定的重力对齐世界参考系，Z 轴向上，水平航向是连接时建立的相对航向，不是地理北向。不显示板子或随板子旋转的方向线，也不把旋转转换成虚拟笔尖位移。空间页归零会同步重置画笔原点，保留已有笔迹。

轨迹核心移植 gaitmap 2.6.0 的 9 状态 ESKF + RTS：按住时前向估计，松开后利用整笔数据回修已有笔迹；静止段加入零速观测，起止速度近似为零。没有平地、Z 归零或闭合笔画假设，不要求先做静止校准。实时预览和最终笔迹可能有差异。算法内部仍使用惯性预测，目标是短笔画的近似形状，按键时已经快速移动或长时间匀速运动会影响结果。源码与 MIT 许可在 `trajectory.py` 和 `vendor/gaitmap-PORT.md`，不需安装整套 gaitmap。

删除旧的加速度死区、速度衰减及 3 m/s、单笔 5 m 门槛；单笔历史上限为 12000 个样本（200 Hz 时约一分钟），极端异常坐标超过 100 m 时暂停。断流时保留已显示笔迹，须松开再按下；不对不完整笔画做整笔替换。实体 KEY 需要 r5 的 `RAW_KEY` 数据。演示设备提供独立“模拟 KEY”按钮，不向真实设备发送虚拟按键。

## 曲线与记录

“实时数据”显示最近约 6 秒的加速度和角速度曲线，同时显示板端漏采、USB 丢包、IMU 错误及拒绝计数。界面曲线显示率为 50 Hz，采集文件保留收到的全部原始样本。

“采集记录”中填写用户、会话、动作标签和速度，开始/停止后可下载：

- `.csv`：六轴数据、序号、板端时间、主机时间及标签。
- `.events.jsonl`：采集期间的非 RAW 协议事件；没有事件时文件可为空。
- `.summary.json`：计数、序号缺口、末次状态和元数据。

文件保存在 `GUI/data/captures`。断开时会结束并保存当前记录。演示设备只生成模拟数据，界面和文件都带标记，永不调用真实键盘；学习时用“按住录制”按钮模拟 KEY，按下/松开才会录制一次，不会自动补齐三次示范。

## 连接问题

- 串口不存在：刷新串口列表，检查 USB 数据线、接口和 Windows 设备管理器。
- 串口被占用：关闭串口助手、CLI 采集器或另一控制台后再连接。
- 三秒握手超时：确认板上运行本项目固件且 USB CDC 工作正常。
- 槽位未同步且事件有 `BAD_COMMAND`：当前固件缺少 `list`，使用本次新 HEX。
- `ClearCommError`：立即关闭失效句柄，最多自动重连三次；只跟随相同 USB 序列号的设备，新 STATUS 握手后才恢复数据流，不重放保存/删除/学习命令，不恢复快捷键。占用/权限错误需解除占用后连接。r6 修复了已确认的 USB suspend/resume 时钟缺陷，尚不能断言它是所有断连的根因。

服务日志位于 `GUI/data/gui.log`。应用只监听本机回环地址，不提供远程控制；写操作验证本地会话 token 和请求来源。

界面版本或服务实例变化时自动刷新一次，保留当前页面和草稿；延迟加载不会切回旧页面。首次从旧版本升级需刷新原有标签页。

## 开发验证

在 `GUI` 目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_backend test_pose test_trajectory test_pen_motion test_server
```

可选的浏览器测试需要 Node.js 和本机 Chrome：

```powershell
npm install --prefix dev-tools
node dev-tools/verify-ui.cjs
node dev-tools/test-air-pen.mjs
node dev-tools/verify-air-pen.cjs
```

浏览器测试会启动独立端口和临时数据目录，只连接模拟器，覆盖录制、保存、取消、删除、设置、采集下载、图表与三维画面像素、动态姿态、归零、空中画笔及桌面/移动布局，不操作真实串口。截图在 `dev-tools/screenshots`。
